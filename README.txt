實驗室畢業紀念網站 v1

【本機預覽】
直接雙擊 index.html。

【發布到 GitHub Pages】
1. 建立 GitHub repository，例如 lab-memories
2. 把此資料夾內的 index.html 和 images 資料夾全部上傳
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / root → Save
6. 等待約 1–3 分鐘取得公開網址

【音樂】
Have It All 使用 Jason Mraz 官方 YouTube 影片嵌入。
瀏覽器通常禁止網站自動播放有聲音的內容，因此老師需要按一次「播放」。
網站沒有附帶或重新散布歌曲 MP3。
